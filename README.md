# cad-birdhouse
This is a birdhouse I created on OnShape! It is meant to be *simple*, *affordable*, <ins>feature a birdbath</ins>, and it <ins>has a large ring for easy hanging</ins>! I decided to create this birdhouse so I can use it in my own home, and I also generally thought this would be a cool project to make. I also created a poster and research slides to assist in the creation of this project!
